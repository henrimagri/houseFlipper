# Visualizador 3D

Controles com modelo: orbit, zoom, fullscreen, reload.

Sem modelo: fallback explícito, convite para enviar GLB, dados cadastrais, cômodos inferidos do anúncio (origem `advertiser`/`inference`, `available=false`).

Simulação de reforma só aparece como feature se o produto tiver `renovation_simulation` (House Flipper). A UI não oferece acabamento como se já existisse motor de materiais.
