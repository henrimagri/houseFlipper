# Limitações 3D

- Fotos isoladas de cômodos diferentes não reconstroem a casa.
- Plantas sem cotas não geram medidas.
- GLB de um imóvel nunca é exibido em outro.
- Sem WebXR nesta entrega.
- CSP: `worker-src 'self' blob:` e `connect-src` com `blob:` para o loader.
- A tela `/ia-inteligente/analise/{id}` gera um layout ilustrativo a partir de área/cômodos do anúncio. Não é fotogrametria.
