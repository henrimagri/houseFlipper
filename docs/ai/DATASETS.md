# Datasets

O dataset inicial está em `services/ai-worker/training/source_examples.json`. São 18 exemplos sintéticos revisados, sem dados pessoais e sem conteúdo copiado de portais. O preparador gera 12 exemplos de treino, 3 de validação e 3 de teste, com hash por exemplo e hash do dataset.
